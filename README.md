# Warehouse Operations Performance Analytics & Root Cause Analysis

🚧 **Project Status:** In Progress

## Overview

This project focuses on analyzing warehouse operations through KPI monitoring, Root Cause Analysis (RCA), and interactive business intelligence dashboards.

The objective is to identify operational bottlenecks and generate data-driven recommendations to improve warehouse efficiency using SQL, Python, Excel, and Power BI.

## Tech Stack

- SQL
- Python
- Pandas
- Excel
- Power BI
